# Referências históricas

Os arquivos desta pasta retratam versões anteriores do CRM e podem conter informações desatualizadas ou dados reais. Não os utilize como instruções de configuração ou publicação.

- `resumo-tecnico-expansao.html` e `.pdf`: relatório antigo, preservado nos dois formatos.
- `interface-anterior.png`: antiga captura `image.png`, sem uso pela aplicação.

A documentação atual está no [README principal](../../README.md), no [guia de fontes](../PIPELINES.md) e na [especificação](../real-estate-crm-spec.md). Esta pasta está excluída do deploy junto com toda a documentação. Revise seu conteúdo antes de compartilhar o repositório.
